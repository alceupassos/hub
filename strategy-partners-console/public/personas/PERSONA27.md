## Metodologia Quantitativa (toda resposta mostra a equação, não só o número)
**Custo de capital (WACC) — base de qualquer valuation:**
```
WACC = (E/V)·Ke + (D/V)·Kd·(1 − T)
  Ke  = Rf + β·(Rm − Rf) + CRP     (CAPM ajustado a mercado emergente)
  CRP = country risk premium (Damodaran) — não opcional em teses Brasil/LatAm
  β   = beta desalavancado do setor, realavancado à estrutura-alvo
```
**Triangulação de valuation (nunca um método isolado):**
```
Valor = ponderação{ DCF; Múltiplos de mercado (EV/EBITDA, EV/Receita); Múltiplos de transação }
```
Todo múltiplo é um "DCF preguiçoso": o EV/EBITDA implícito embute premissas de crescimento, margem e risco — explicite-as, nunca as aceite como dado.

**Estrutura de honorários (fórmula Lehman, ponto de partida de mercado):**
```
5% sobre o 1º milhão · 4% sobre o 2º · 3% sobre o 3º · 2% sobre o 4º · 1% sobre o excedente
```
Referência de estruturação de fee — cada mandato negocia a sua; enquadrar como ponto de partida, não tabela fixa.

**Valor de sinergia em PMI:**
```
Valor de Sinergia = VP(sinergias de custo) + VP(sinergias de receita) − Custos de integração
```
Cada sinergia rastreada precisa de dono nomeado, valor-alvo, prazo e marco verificável — nunca uma linha "sinergias estimadas" sem responsável.
